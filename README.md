# 🌾 Agriculture Information Portal

A modern agriculture dashboard web application developed using React.js and Node.js.

This platform provides agricultural information services including weather monitoring, crop advisory, and market analytics through a clean dashboard interface.

---
Link:https://agriculuture.netlify.app/

# 📌 Project Overview

The Agriculture Information Portal is designed to provide useful agricultural insights and awareness through a simple and interactive web application.

The system includes:

- 🌦 Weather Monitoring
- 🌾 Crop Advisory
- 📊 Market Price Dashboard
- 📈 Agricultural Analytics
- 🖥 Government-style Dashboard UI

---

# 🚀 Features

## 🌦 Weather Module
- Current location weather
- Temperature details
- Humidity information
- Wind speed monitoring
- Live weather API integration

---

## 🌾 Crop Advisory Module
- Crop recommendations
- Seasonal crop guidance
- Agriculture awareness
- Farmer support information

---

## 📊 Market Dashboard
- Crop market prices
- Market status updates
- Dashboard analytics
- Search and filter functionality
- Structured market data sections

---

## 🖥 Dashboard UI
- Responsive layout
- Navigation tabs
- Hero background images
- Information cards
- Market overview sections
- Government-style design
